# Archived design document

`Agro-Stake_Documentation.pdf` is an early conceptual design document from the
project's initial phase. It is preserved for provenance, not as current
technical documentation.

Use it with these caveats:

- It predates the final RGB v2 model and the measured test results.
- Several claims in it (model size, accuracy, deployment status, and feature
  scope) are superseded by [`../results.md`](../results.md),
  [`../versions.md`](../versions.md), and [`../architecture.md`](../architecture.md).
- It is not peer-reviewed and was not updated after the experiments.
- It may describe planned features that were never implemented or were moved to
  `firmware/experimental/`.

For anything you intend to rely on, use the code and the measured results, not
this PDF.
